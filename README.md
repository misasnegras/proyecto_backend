# Proyecto - Plataforma de Noticias

Sistema backend desarrollado en Python y Django para centralizar la gestión de publicaciones periodísticas de un medio digital, mantener trazabilidad histórica de estados editoriales, validar reglas de negocio, realizar consultas multicriterio y generar indicadores de gestión.

## Requisitos
- Python 3.11 o superior
- Git
